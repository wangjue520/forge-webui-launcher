## 一、「一键启动」页

日常就用这一页。

### 页面上各部分是什么

| 区域 | 说明 |
|---|---|
| 根目录 | 部署完自动填好。WebUI 是含 `webui.bat` 的文件夹，ComfyUI 是含 `main.py` 的文件夹 |
| 解释器 / Git 路径 | **留空**，自动检测。只有整合包启动报 `No module named` 时才手动填 |
| 启动参数 | 只读预览，由「高级选项」页生成，不用在这里改 |
| 启动成功后自动在浏览器打开 | 建议勾上 |
| 一键启动 / 停止 / 在浏览器中打开 | 主按钮 |
| 输出图片 | 文生图、当天文生图、图生图、当天图生图——一键打开出图文件夹 |
| 运行日志 | WebUI 的实时输出，出错时看这里 |

多实例时页面顶部还有每个实例的状态卡片，每个实例都能单独启动 / 停止。

### 启动步骤

1. 点 **「一键启动」**，按钮变成「启动前检查…」
2. 日志开始滚动。**第一次启动比较慢**（可能还要装一些依赖、编译），之后一般 30 秒~2 分钟
3. 日志里出现 `Running on local URL: http://127.0.0.1:7860` 后，浏览器自动打开网页
4. 没自动打开就点「在浏览器中打开」

### 点启动时可能弹出的对话框

| 弹窗 | 意思 | 怎么选 |
|---|---|---|
| 检测到残留进程 | 上次没关干净，端口被占 | 「结束并启动」 |
| 检测到配置冲突 | 整合包的 `webui-user.bat` 里写死了旧参数 | 「清空并启动」（原文件自动备份成 .bak） |
| 路径含中文 / 空格 | 部分依赖有 bug | 建议换纯英文路径；也可以先继续试试 |
| --listen + 允许不安全扩展访问 同时开着 | 局域网里任何人都能往你电脑装代码 | 至少关掉一个 |

### 关闭

1. 先在启动器点 **「停止」**（会把 WebUI 整个进程树干净关掉，释放显存）
2. 再关启动器窗口

如果实例还在跑就直接关启动器，会弹框提醒你哪些实例在运行。

## 二、在 Forge Neo 网页里出第一张图

浏览器打开后是 Forge 的网页界面（英文；想要中文看下面 [第五节](#五把网页界面变成中文)）。

### 最基本的 6 步

```
┌───────────────────────────────────────────────────────────────┐
│ UI: [xl ▼]   Checkpoint: [你的模型 ▼]   VAE / Text Encoder: [ ▼] │  ← ① ② ③
├───────────────────────────────────────────────────────────────┤
│ txt2img │ img2img │ ...                                         │
│ ┌ Prompt ──────────────────────────────┐   [ Generate ]  ← ⑥    │
│ │ masterpiece, 1girl, ...         ④    │                        │
│ └──────────────────────────────────────┘                        │
│ ┌ Negative Prompt ─────────────────────┐                        │
│ │ worst quality, low quality, ...      │                        │
│ └──────────────────────────────────────┘                        │
│ Sampling method / Schedule type / Steps / CFG / Width / Height ⑤ │
└───────────────────────────────────────────────────────────────┘
```

1. **UI 预设**（左上角，写着 sd / xl / flux / …）：按你的模型选。SD1.5 选 `sd`，SDXL / Illustrious / NoobAI / Pony 选 `xl`，Flux 选 `flux`，Anima 选 `anima`（各版本名称可能略有不同）。它会把采样器、尺寸等切成适合这类模型的默认值
2. **Checkpoint**：选你下载的大模型。刚下的模型没出现就点旁边的 🔄 刷新
3. **VAE / Text Encoder**：
   - SD1.5 / SDXL / Illustrious 等：**留空（或 Automatic）就行**，模型自带
   - Anima、Flux、Qwen-Image、Z-Image 等新模型：**必须在这里选上配套的文本编码器和 VAE**（可以多选），见 [Anima 教程](05-Anima使用教程.md)
4. **Prompt（正向提示词）**：想画什么。**Negative Prompt（负向提示词）**：不想要什么
5. **参数**：见下表
6. 点右边的 **Generate**，图出现在右边，同时自动保存到输出文件夹

### 参数怎么填（新手照抄）

| 模型类型 | 尺寸（宽×高） | Steps 步数 | CFG | 采样器 Sampling method / Schedule type |
|---|---|---|---|---|
| SD 1.5 | 512×768、768×512 | 20~30 | 6~7 | DPM++ 2M / Karras |
| SDXL / Illustrious / NoobAI / Pony | 832×1216、1024×1024、1216×832 | 25~30 | 5~7 | Euler a / Normal（或 DPM++ 2M / Karras） |
| Anima | 832×1216、1024×1024 | 30~50（Turbo 版 8~12） | 4~5（Turbo 版 1） | er_sde 或 Euler a |
| Flux.1 dev | 832×1216、1024×1024 | 20~30 | CFG 1，Distilled CFG 3.5 | Euler / Simple |

> **最重要的规则：先看模型页的说明**。Civitai 模型页一般会写作者推荐的采样器、步数、CFG、尺寸、Clip Skip，照着填效果最好。

其他常用参数：

| 参数 | 说明 |
|---|---|
| Batch count | 连续生成几次 |
| Batch size | 一次同时生成几张（吃显存，显存小保持 1） |
| Seed | 随机种子。-1 = 每次随机；固定一个数字 + 同样参数 = 出同一张图 |
| Hires. fix | 高清修复：先出小图再放大重绘。勾上后 Upscaler 选 `4x-UltraSharp` 或 `R-ESRGAN 4x+ Anime6B`，Upscale by 1.5，Denoising 0.3~0.45。显存小慎用 |
| Clip skip | 二次元 SD1.5 / Pony / Illustrious 模型常要求 2，看模型说明（Settings 里调） |

### 提示词怎么写

**二次元模型（Illustrious / NoobAI / Pony / Anima）**：用英文**标签**，逗号分隔：

```
masterpiece, best quality, 1girl, solo, long hair, silver hair, blue eyes, school uniform, smile, cherry blossoms, outdoors
```

负向：
```
worst quality, low quality, bad anatomy, bad hands, extra fingers, blurry, jpeg artifacts, watermark, signature
```

**写实 / 新模型（Flux、Qwen-Image、Z-Image 等）**：用英文**自然语言句子**描述就行：

```
A young woman standing under cherry blossoms at sunset, soft light, wearing a white dress, shallow depth of field
```

**用 LoRA**：在提示词里加 `<lora:LoRA文件名:0.8>`，数字是强度（0.6~1 常用）。再加上 LoRA 的**触发词**（模型页或启动器「模型管理」里能看到）。
最方便的办法：网页里切到 **Lora** 标签页，点一下 LoRA 卡片就自动插入；或者在启动器「模型管理 → LoRA」里点「复制 lora 调用格式」。

> 不会写提示词？
> - 在 Civitai 上找一张喜欢的图，下载原图拖进启动器「[图片信息](07-输出管理-图片信息-WD14反推.md#二图片信息读取任何图的生成参数)」页，提示词、参数、用了哪些模型全都能读出来，还能一键补齐缺的模型
> - 装「Prompt All-in-One」插件可以直接写中文，自动翻译成英文标签

## 三、图生图、局部重绘（简述）

| 标签页 | 用途 |
|---|---|
| img2img | 上传一张图，按提示词重画。**Denoising strength** 越小越像原图（0.3~0.5 微调，0.6~0.8 大改） |
| img2img → Inpaint | 用画笔涂掉一块，只重画涂掉的部分（修手、换衣服、去杂物） |
| Extras | 单纯放大图片，不重画 |
| PNG Info | 读图片参数（启动器的「图片信息」页更强） |

## 四、ComfyUI 最简单的用法

ComfyUI 是节点式的，新手建议这样起步：

1. 启动后网页里默认就有一个文生图工作流：在 **Load Checkpoint** 节点选模型 → 改提示词 → 点右上角 **Run / Queue**
2. **最省事的学法：拖图**。把别人用 ComfyUI 出的原图（PNG）直接拖进 ComfyUI 网页，整个工作流就加载出来了
3. 缺节点（红框）：打开 **Manager → Install Missing Custom Nodes**，一键装
4. 缺模型：把那张图拖进启动器「图片信息」页 →「检测缺失模型」

> ComfyUI 的新模型（Anima、Flux、Qwen-Image 等）主模型要放 `models\diffusion_models`，用 **Load Diffusion Model** 节点加载，而不是 Load Checkpoint。详见 [Anima 教程](05-Anima使用教程.md)。

## 五、把网页界面变成中文

1. 启动器「常用插件」→ 勾选「**简体中文汉化 (zh_CN)**」→「安装选中项」
2. 在启动器里「停止」再「一键启动」
3. 网页里：**Settings → User interface → Localization** 选 `zh_CN` → 点上面的 **Apply settings** → **Reload UI**

最后一步是网页内的设置，启动器没法替你点，只需要做一次。

## 六、高级选项（按需调整，新手全保持「自动」）

侧栏「高级选项」。改动自动保存，**下次点「一键启动」时生效**。多实例时页面顶部先选「要设置的实例」。

### 所属分支

部署时自动设好。只有你手动登记的整合包启动报「unrecognized arguments」时才需要改：新版 Neo 选「Neo 版（新版参数）」，老 Neo 整合包选「Neo 版（旧版参数）」。

### 性能设置

| 选项 | 什么时候改 |
|---|---|
| GPU 编号 | 多显卡时选用哪块（0、1…） |
| 显存策略 | 爆显存（`CUDA out of memory` / `OOM`）时选「低显存模式」；还不行选「极限低显存」。会变慢 |
| 预留显存 | 出图时桌面卡、浏览器卡，填 1~2（GB）给系统留点 |
| 计算精度 | 出图**全黑 / 全灰 / 一片噪点**时选「全部使用 FP32」 |
| UNet / VAE / 文本编码器精度（Neo） | 显存紧张：UNet 选 FP8 e4m3fn、VAE 选 BF16；一般保持「跟随全局」 |
| 注意力实现 | 保持自动 |
| 快速 FP16、可扩展显存段 | 40 / 50 系显卡想压榨性能可以试试 |
| xFormers / Flash / Sage | 只负责「首次启动时安装」对应加速库，实际用哪个 Forge 自己挑。不懂就不勾 |
| ComfyUI 加速（ComfyUI 实例） | Sage / Flash 要先装好对应的包；`--fast` 新卡更快，个别模型画质会变 |

### 网络与其他

| 选项 | 说明 |
|---|---|
| 局域网访问（--listen） | 想用手机 / 另一台电脑访问时勾上，访问 `http://电脑IP:7860` |
| 启用 API（--api） | 给其他软件（如 SillyTavern、Krita 插件）调用 |
| 生成公网分享链接（--share） | 生成一个 gradio 公网链接，**任何拿到链接的人都能用你的显卡**，慎用 |
| 允许不安全的扩展访问 | 想在网页里直接装插件时才勾；和 --listen 一起开很危险 |
| 启动后自动打开浏览器（--autolaunch） | 让 Forge 自己开浏览器（和启动器那个二选一，不会开两个） |
| 跳过 Python 版本检查 | venv 版本和 webui.bat 期望不一致时先试试 |
| 禁用模型哈希计算（--no-hashing） | 老整合包加载模型报 `file_digest` 时勾上；或者用「环境部署 → 写入 hashlib 兼容补丁」 |
| 网页主题 | Forge 网页深色 / 浅色 |
| 端口 | 默认 WebUI 7860、ComfyUI 8188，多实例会自动错开 |
| 自定义追加参数 | 其他想手动加的命令行参数，空格分隔 |

### 仅供参考

GPU Weight、共享显存回退、模型哈希这些**命令行设不了**，这里只是提醒你去哪里设：

- **GPU Weight**：网页顶部 / Settings → Optimizations
- **共享显存回退**（显存爆了用内存顶上，慢但不报错）：NVIDIA 控制面板 → 管理 3D 设置 → 程序设置 → 选 WebUI 用的 python.exe →「CUDA - Sysmem Fallback Policy」
