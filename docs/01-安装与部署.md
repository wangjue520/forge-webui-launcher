# 01 · 安装启动器 & 部署 WebUI / ComfyUI

> [← 返回教程目录](README.md)

这一篇解决「从零到能打开网页」：下载启动器 → 第一次运行 → 部署 Forge / ComfyUI。
已经有秋叶整合包等现成安装的，看 [第四节](#四已经有整合包不用重新部署)，可以不用重新部署。

---

## 一、准备工作（先看这个，能省掉 80% 的问题）

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10（1803 以上）/ Windows 11，64 位 |
| 显卡 | **NVIDIA（N 卡）**：6GB 显存以上体验较好，4GB 能跑（会慢）<br>**AMD（A 卡）**：RX 5000 / 6000 / 7000 / 9000 系列，部署时选「AMD 显卡（ROCm）」<br>核显 / 纯 CPU：能跑但非常慢，不推荐 |
| 内存 | 16GB 起步，**32GB 推荐**（大模型、视频模型会把放不下显存的部分挪到内存） |
| 硬盘 | 至少留 **30GB**（Forge 本体 + 依赖约 10GB，一个模型 2~7GB）。放 **SSD** 加载模型快很多 |
| 显卡驱动 | N 卡建议更新到最新版（Game Ready / Studio 都行）。驱动低于 580 也能用，启动器会自动换兼容的 torch |
| 软件 | **什么都不用装**。Python、Git 都由启动器自动下载便携版，不碰你电脑里已有的 Python |

### 路径一定要用纯英文

**启动器和部署目录都放在纯英文、无空格、无括号的路径**，例如 `D:\AI\launcher`、`D:\AI\forge`。

❌ 不要放：
- 桌面（很多人的用户名是中文，桌面路径就带中文）
- `D:\新建文件夹\`、`D:\AI 绘画\`（中文、空格）
- `D:\forge-webui-launcher-main (1)\`（浏览器重复下载自动加的 `(1)`）

路径里有中文、空格、括号、`&`、`!`、`%` 是绝大多数「莫名其妙报错」的根源，这是 Python 生态和 Windows 命令行本身的限制，启动器绕不过去。

## 二、下载启动器、第一次运行

### 1. 下载

- GitHub 仓库主页 → 绿色 **Code** 按钮 → **Download ZIP**
- 或者用别人发给你的压缩包

### 2. 解压

1. 右键压缩包 →「全部解压缩」/「解压到当前文件夹」，解压到比如 `D:\AI\`
2. **不要在压缩软件里直接双击运行**，一定要先解压出来

解压后的样子：

```
D:\AI\
└─ forge-webui-launcher\        ← 启动器本体
   ├─ 启动WWY启动器.bat          ← 双击它
   ├─ web\
   └─ ……（其他文件不用管）
```

> 小技巧：`启动WWY启动器.bat` 可以复制一份放到 `forge-webui-launcher` 文件夹**旁边**（`D:\AI\启动WWY启动器.bat`），双击效果一样——它会自己找到旁边的启动器文件夹。

### 3. 第一次双击

双击 `启动WWY启动器.bat`，会弹出一个黑色命令行窗口，自动完成：

1. 下载便携版 Python（约 30MB，带官方哈希校验）
2. 在启动器文件夹里建一个独立的 `.venv` 环境，装好启动器自己的依赖
3. 在桌面和启动器文件夹里各建一个带图标的「WWY 启动器」快捷方式
4. 弹出启动器窗口

第一次大约 1~3 分钟，**以后都是秒开**，以后直接双击桌面快捷方式即可。

**第一次可能遇到的问题：**

| 现象 | 处理 |
|---|---|
| 黑窗口一闪就没了 / 提示「不是内部或外部命令」 | 路径有中文/空格/括号，或者没解压就运行。换纯英文路径重新解压 |
| 下载 Python 失败 | 网络抖动，启动器会自动重试；还不行就关掉窗口再双击一次 |
| 窗口是白屏 | 系统缺 WebView2（极少数精简版系统），装微软官方的：https://developer.microsoft.com/microsoft-edge/webview2/ |
| 杀毒软件报毒 / 文件被删 | 国产杀软误报。把启动器目录和以后的部署目录加入白名单 |
| 界面太大或太小 | 按住 **Ctrl + 鼠标滚轮** 缩放，会自动记住 |

## 三、部署 WebUI（第一次需要，之后不用）

部署 = 把 Forge WebUI 或 ComfyUI 本体下载下来并装好运行环境。

打开侧栏 **「环境部署」**（装了两个以上实例后，这个入口在「实例管理 → 部署新的实例…」）。

### 第 1 步：环境检测

页面最上面显示 Git、Python 的检测结果。**显示没找到也没关系**，下面勾选「自动下载便携版 Python + Git」就会自动下。

### 第 2 步：选择要部署的程序

| 选项 | 适合谁 |
|---|---|
| **Neo 版（推荐）** | 绝大多数人选这个。界面是传统的 WebUI（填提示词点生成），支持 SD1.5、SDXL、Illustrious、Anima、Flux、Qwen-Image、Z-Image、Wan 视频等新模型，更新最勤 |
| Neo · H3 视频版 | 想跑 MiniMax-H3 视频生成的人。需要显卡 ≥ 12GB、内存建议 48GB 以上（64GB 最稳）。不跑视频就选上面的普通 Neo |
| 常规版 / Classic | lllyasviel 的原版 Forge，很久不更新了，只有老插件必须用它时才选 |
| ComfyUI | 节点式工作流，灵活但上手难。新手建议先用 Neo |

> 不确定就选 **Neo 版**。以后想换，再部署一个装到别的目录就行，两个可以共存。

### 第 3 步：选择显卡

- **NVIDIA 显卡（CUDA）**：N 卡选这个（默认）
- **AMD 显卡（ROCm）**：A 卡选这个，再在下拉框里选你的型号（启动器会自动检测，一般已经选好）

页面会显示检测到的显卡。A 卡的说明见 [第五节](#五a-卡amd用户看这里)。

### 第 4 步：选择安装目录

1. 点「浏览…」，选一个**空文件夹**或者**还不存在的文件夹**，比如 `D:\AI\forge`
2. 点「检测该目录」，会告诉你：
   - **空目录 / 不存在** → 可以部署
   - **检测到已有安装** → 会跳过下载源码，只补齐环境
   - **上次部署没完成的残留** → 可以接着部署
   - **非空且不是安装目录** → 换一个目录

> ❌ 不要选启动器自己的文件夹，也不要选 `C:\Program Files` 这种系统目录。

### 第 5 步：开始部署

1. 保持勾选「**自动下载便携版 Python + Git**」
2. （部署 ComfyUI 时）下面会出现「随部署一起安装的常用节点」，保持默认勾选即可
3. 点 **「开始部署」**

部署过程（看下方「部署日志」）：

| 阶段 | 大概耗时 | 说明 |
|---|---|---|
| 下载便携 Python + Git | 1~5 分钟 | 约 100~150MB |
| 下载源码（git clone） | 1~5 分钟 | 自动走 GitHub 加速 |
| 预下载 torch | 5~30 分钟 | **最大的一块，2~3GB**，断点续传 |
| 安装其他依赖 | 5~30 分钟 | 没有进度条，只有「仍在执行… 当前网速 x MB/s」的心跳 |
| 自动验证 | 1~3 分钟 | 试启动一次，确认能用 |

⚠️ **日志很久不动不等于卡死**。看心跳里的「当前网速」：有网速就是在下载；连续一分半「网速几乎为 0」才可能是卡住了，这时点「取消」再点「开始部署」，**会从断点继续，不会从头下**。

部署成功后：
- 自动登记为一个「实例」，自动填好「一键启动」页的路径
- 接下来去 [下载模型](03-模型下载-C站与liblib.md)，然后 [启动出图](02-启动与出图.md)

### 部署失败怎么办

1. **再点一次「开始部署」**——大部分失败是网络抖动，断点续传会接着来
2. 「启动器设置 → 下载加速」改成「总是使用国内镜像」（国内）或「总是使用官方源」（开了梯子）后再试
3. 还不行：用备用整合包（百度网盘）：https://pan.baidu.com/s/1SV-YxTe-5DhA4PPjDk-neQ?pwd=26u8 提取码 `26u8`，解压到纯英文路径后，在「安装目录」选它，再点「开始部署」——会跳过下载源码，只补齐环境
4. 把「部署日志」最后 30 行截图发 Issue / 发给作者

> **要不要开梯子？** N 卡部署：国内网络不开梯子也行，启动器会自动走国内镜像；开了梯子就把「下载加速」选成「总是使用官方源」，**不要一边开梯子一边走国内镜像**（容易两头都慢）。A 卡部署：AMD 的 torch 源没有国内镜像，**建议开梯子**。

## 四、已经有整合包，不用重新部署

秋叶整合包、别人打包好的 Forge / ComfyUI，都能直接用：

1. 打开「一键启动」页
2. 「根目录」点「浏览…」：
   - WebUI / Forge：选**包含 `webui.bat` 的那个文件夹**
   - ComfyUI：选**包含 `main.py` 的那个文件夹**（秋叶 ComfyUI 包一般是里面的 `ComfyUI` 文件夹）
3. 「Python 解释器」「Git」留空，启动器会自动找整合包自带的 `python\python.exe`、`git\cmd\git.exe`
4. 直接点「一键启动」

如果启动报 `No module named 'xxx'`：启动器没找对整合包自带的 Python，在「Python 解释器」里手动填整合包里 `python.exe` 的完整路径。

想同时登记多个安装：「实例管理 → 添加已有安装」，见 [06 · 多实例](06-模型管理与共享模型库.md#五多实例)。

## 五、A 卡（AMD）用户看这里

### 能用哪些 A 卡

| 架构 | 型号 |
|---|---|
| gfx1201 / gfx1200 | RX 9070 / 9070 XT / 9060 / 9060 XT、AI PRO R9700 |
| gfx1100 / 1101 / 1102 | RX 7900 XTX / XT / GRE、7800 XT、7700 XT、7600 / 7600 XT |
| gfx1030 / 1031 / 1032 / 1034 | RX 6950 XT ~ 6400 |
| gfx1035 | 680M / 660M 核显 |
| gfx1010 | RX 5700 / 5600 |
| gfx1151 / gfx1103（实验性） | Ryzen AI Max（8060S）、780M / 760M 核显 |

### A 卡部署步骤

1. **更新 AMD 显卡驱动**到最新（Adrenalin）
2. **开梯子**（AMD 的 torch 源在国外，没有国内镜像，约 3~4GB）
3. 「环境部署」→ 程序选 **Neo 版** 或 **ComfyUI**（Classic 不支持 A 卡）
4. 「显卡」选 **AMD 显卡（ROCm）**，确认下拉框里的型号对得上你的显卡
5. 选安装目录 → 开始部署

启动器会自动：预下载 AMD 版 torch（断点续传）、装好配套的 torchvision、初始化 ROCm、启动时自动加 A 卡需要的参数和环境变量。

### 已经装好的 N 卡环境换成 A 卡（或反过来）

换了显卡不用重新部署：

1. 「环境部署」→「安装目录」选那个已装好的 WebUI / ComfyUI 目录
2. 「显卡」选新显卡类型（A 卡再选型号）
3. 点 **「把安装目录的环境切换成所选显卡…」** →「开始切换」

只重装 torch，**模型、插件、设置都不动**。

### A 卡常见坑

- **开了「显卡伪装」类软件**（比如无极画质助手把显卡伪装成 GTX 750 之类）：系统和启动器都会认错显卡，装错环境。**先关掉伪装，重启电脑**，再部署 / 切换环境
- 启动报 `torchvision::nms does not exist`：环境里混了 N 卡版的 torchvision。用上面的「把安装目录的环境切换成所选显卡…」重新切一次 AMD 即可自动修好
- 第一次出图特别慢：ROCm 第一次要编译内核，第二张开始就正常了

## 六、环境诊断（已有安装出问题时）

「环境部署」页下方「环境诊断」（只对 Forge 显示）：

| 按钮 | 什么时候用 |
|---|---|
| 检测现有 venv 版本 | 启动报 `Requires-Python` 或 Python 版本不一致。检测后可以删掉旧 venv，下次启动自动用正确的 Python 重建 |
| 写入 hashlib 兼容补丁 | 加载模型报 `hashlib has no attribute 'file_digest'`（老整合包常见） |

另外：
- **Forge 目录整个剪切搬家也没问题**，启动前会自动修正 venv 里记录的旧路径
- **更新 Forge 本体**：对已有目录再点一次「开始部署」，会跳过下载源码，只更新依赖并验证；Neo 也可以在网页里自带的更新功能更新
