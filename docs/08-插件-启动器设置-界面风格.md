## 一、常用插件

侧栏「常用插件」。插件（扩展 / 节点）给 WebUI / ComfyUI 增加功能。

页面顶部「**安装到**」写着装给哪个实例、装进哪个目录；多实例时可以直接在这里换安装目标。

### WebUI（Forge）实例

1. 勾选想装的插件（「勾选推荐项」一键勾上推荐的）
2. 点「**安装选中项**」，看下方日志
3. 装完在「一键启动」页**停止再启动** WebUI 才生效

列表会**按你的分支自动适配**：Neo 上不能用的原版插件会自动换成 Neo 专用的分支版本，实在没有的就不显示。所以**在这里装比在网页里自己装更不容易出错**。

| 插件 | 干什么用 | 新手推荐 |
|---|---|---|
| 简体中文汉化 (zh_CN) | 网页界面变中文（装完还要在网页 Settings 里选一次，见 [02 · 第五节](02-启动与出图.md#五把网页界面变成中文)） | ⭐ |
| ADetailer | **自动修脸、修手**，出图质量提升明显 | ⭐ |
| Tag Autocomplete | 写提示词时自动补全标签、LoRA 名 | ⭐ |

| Model Keyword | 触发词库，配合 Tag Autocomplete 自动补 LoRA 触发词 | |
| WD14 Tagger | 网页里的反推标签（启动器自带的「WD14 反推」页功能一样，不装也行） | |
| Dynamic Prompts | 通配符、随机组合，批量出不同的图 | |
| TIPO | 输几个标签，自动扩写成完整提示词 | |
| Civitai Helper | 给网页里的 LoRA 卡片拉封面图和触发词 | |
| Infinite Image Browsing | 网页里的出图浏览器（启动器的「输出管理」页也能做） | |

| 宽高比 / 分辨率快捷按钮 | 一键切常用尺寸 | |

| NegPiP | 在正向框里写负权重 | |
| Openpose Editor | 手动摆姿势骨架，配合 ControlNet | |

### ComfyUI 实例

显示 ComfyUI 专用节点清单，分三组：

- **推荐**：Manager（节点管理器）、rgthree、Custom-Scripts、Impact Pack + Subpack（FaceDetailer 修脸）、UltimateSDUpscale、VideoHelperSuite、KJNodes——部署 ComfyUI 时默认已经一起装好
- **按需**：controlnet_aux（ControlNet 预处理器）、Inpaint-CropAndStitch、WD14-Tagger、Image-Saver（让参数能被 C 站和「图片信息」识别）、GGUF（量化模型）、Easy-Use、Crystools（显存监控）、IPAdapter_plus、Lora-Manager
- **作者自制**：Neo-Sampler（在 ComfyUI 里出和 Forge Neo 一样的图）、Inpaint-WebUI-Style（WebUI 风格的局部重绘）

安装时会用该实例自己的 Python 把节点依赖一起装好（不会把你的 torch 换成 CPU 版）。**实例运行中不能安装**，先停止。

> 打开别人的工作流提示缺节点：ComfyUI 网页里 **Manager → Install Missing Custom Nodes** 一键补装。

## 二、启动器设置

侧栏「启动器设置」，这里是**全局设置**，不属于任何实例。

### 启动器更新

启动器会自动检查新版本，侧栏 logo 下方显示当前版本号。

1. 「检查更新」
2. 有新版本 →「**立即更新**」
3. 更新完**重启启动器**生效

只更新启动器自己的代码。你的配置、模型、便携 Python / Git、WD14 环境全部保留。
（git 下载的走增量更新，ZIP 解压的走整包覆盖，自动选择。）

> 更新 WebUI / ComfyUI 本体不在这里，见 [01 · 环境诊断](01-安装与部署.md#六环境诊断已有安装出问题时)。

### 多实例

「显示多实例功能」。只用一个 WebUI 的不用管；添加第二个实例后自动打开且不能关。见 [06 · 多实例](06-模型管理与共享模型库.md#五多实例)。

### 界面风格

换启动器的皮肤（不影响 WebUI 网页）。选了界面**立即生效**，开屏动画**下次启动**生效。

| 风格 | 样子 |
|---|---|
| 终末地 · 工业终端（默认） | 浅灰工业纸面 + 柠檬黄高亮，带开屏动画 |
| 构型 BAUFORM（深色） | 机能 + 包豪斯 + 未来复古。深色底，机场翻牌式数字时钟和页码，带开屏动画 |
| 极简 · 浅色 / 深色 | 细线、小圆角、没有装饰和动画，最朴素 |
| 液态玻璃 · 浅色 / 深色 | 仿 iOS / macOS 26 的液态玻璃，透明玻璃会折射背后的画面 |
| 矢量突破 · 青色拟生态 | 毛玻璃 + 虚化的立体场景，大圆角、软阴影，第一眼很惊艳 |

> 电脑比较老 / 核显卡顿：选「极简」。

### 功能开关

用不上的页面（比如不训练 LoRA 用不着 WD14 反推）可以从侧栏藏起来，随时再打开。

### 下载加速（国内网络）

| 选项 | 什么时候选 |
|---|---|
| 自动检测（推荐） | 默认。按网络环境自动决定走国内镜像还是官方源 |
| 总是使用国内镜像 | 国内网络，自动检测判断错了的时候 |
| 总是使用官方源 | **开了梯子**，或者人在国外 |

走镜像时：便携 Python / Git、Forge 源码、插件走 GitHub 加速代理；torch 等依赖走清华 / 阿里 PyPI 镜像；WD14 模型走 HuggingFace 镜像。镜像只是优先尝试，失败会自动回退官方源。

换了网络（比如刚开 / 关了梯子）可以点「重新检测网络环境」。

**下载安全**：经加速代理下载的 Python / Git 等程序，都会和官方发布的哈希比对，Git 还会验证微软签名，对不上就拒绝执行，不用担心镜像被篡改。
