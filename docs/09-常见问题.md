# 09 · 常见问题 FAQ

> [← 返回教程目录](README.md)

按 **Ctrl+F** 搜报错里的关键词（比如 `out of memory`、`nms`、`driver`）最快。

**求助前先准备好**：「一键启动」或「环境部署」页日志的**最后 30 行截图**、显卡型号、启动器版本号（侧栏 logo 下方）。

---

## 启动器本身

**Q：双击 bat 一闪而过 / 「不是内部或外部命令」**
路径有中文、空格或括号，或者没解压就在压缩包里运行。解压到纯英文路径（如 `D:\AI\launcher`）再试。

**Q：第一次双击 bat 失败，再双击又好了**
便携 Python 下载偶尔抖动，正常现象。反复失败就换个网络 / 开梯子再试。

**Q：第一次启动黑窗口里全是乱码**
老版本的问题，已修复。重新下载最新版启动器。

**Q：窗口白屏 / WebView2 报错**
系统缺 WebView2 运行时，装微软官方的（免费）：https://developer.microsoft.com/microsoft-edge/webview2/

**Q：杀毒软件报毒 / 文件被删**
国产杀软误报（便携 Python / Git 来自官方，带哈希和签名校验）。把启动器目录和部署目录加白名单。

**Q：启动器怎么更新？**
「启动器设置 → 启动器更新」→ 检查更新 → 立即更新 → 重启启动器。配置、模型、环境全部保留。

**Q：弹出一个 Windows 错误窗口，说某个 DLL 找不到 / 无法定位程序输入点**
老版本切换显卡环境时的残留文件触发的，新版已经屏蔽这类弹窗并会自动清理残留。更新启动器，再「环境部署 → 把安装目录的环境切换成所选显卡…」重新切一次。

## 部署

**Q：部署很久没动静，是不是卡死了？**
看日志里的心跳「当前网速」：有网速就是在下载（torch 2~3GB，慢的网要半小时以上）。连续一分半「网速几乎为 0」才算卡住，点「取消」再「开始部署」，会断点续传。

**Q：自动部署反复失败**
1. 再点一次「开始部署」（断点续传）
2. 「启动器设置 → 下载加速」切换镜像 / 官方源再试
3. 用备用整合包：https://pan.baidu.com/s/1SV-YxTe-5DhA4PPjDk-neQ?pwd=26u8 （提取码 `26u8`），解压后在「安装目录」选它，再点「开始部署」

**Q：要不要开梯子？**
N 卡：不开也行（自动走国内镜像）；开了就把「下载加速」设为「总是使用官方源」。A 卡：建议开（AMD 的 torch 没有国内镜像）。

**Q：提示「此时不应有 X」**
安装路径里有 `()`、`&`、`^`、`%`、`!`。换纯英文路径。

**Q：`error launching git: ??????`**
便携 Git 跑不起来，多半被杀软拦截。把部署目录加白名单再「开始部署」；或者装官方 Git（https://git-scm.com/download/win），取消勾选「自动下载便携版 Python + Git」再部署。

**Q：`CRYPT_E_NO_REVOCATION_CHECK (0x80092012)`**
启动器自带的 Git 已自动处理。自己装的 Git 遇到可执行一次：`git config --system http.schannelCheckRevoke false`

**Q：提示「没有可用的哈希校验基准，已中止（安全策略）」**
拿不到官方校验清单（GitHub 被挡）。换网络 / 开梯子后重新部署。

**Q：`externally-managed-environment` / `managed by uv`**
新版启动器完全不用系统 Python，更新启动器即可。

## 启动

**Q：报 `Please update your GPU driver` / `The NVIDIA driver on your system is too old`**
显卡驱动太旧，装不了最新的 torch。两种办法任选：
- 更新 NVIDIA 驱动到最新版（推荐，新驱动对新显卡和新模型更好）
- 更新启动器到最新版，它会自动给旧驱动换兼容的 torch 版本

**Q：报 `CUDA-capable device(s) is/are busy or unavailable`**
显卡被占用或不可用：
1. **重启电脑**（最常见的解决办法）
2. 关掉「显卡伪装」类软件（如无极画质助手）、游戏加速器、挖矿软件
3. 不要通过远程桌面 / 虚拟机运行
4. 命令行运行 `nvidia-smi`，看 Compute M. 一栏是不是 `E. Process`（独占模式）。是的话用管理员命令行执行 `nvidia-smi -c 0` 改回默认

**Q：端口被占用 / 检测到残留进程**
上次没关干净。弹窗里选「结束并启动」，或者重启电脑。

**Q：`No module named 'xxx'`（整合包）**
启动器没找对整合包自带的 Python。「一键启动」页「Python 解释器」手动填整合包里 `python.exe` 的完整路径。

**Q：venv 版本不一致 / `Requires-Python >=3.x`**
「环境部署」页「检测现有 venv 版本」→ 删除 venv，下次启动自动重建。

**Q：`hashlib has no attribute 'file_digest'`**
「环境部署」页「写入 hashlib 兼容补丁」；或「高级选项」勾「禁用模型 SHA-256 哈希计算」。

**Q：`Bad git executable`**
老版本启动器的问题，更新启动器即可。

**Q：日志有 `Running on local URL` 但网页没打开**
点「在浏览器中打开」。

**Q：一直「启动中」/ 日志有红字**
截最后 30 行发 Issue。

## A 卡（AMD）

**Q：A 卡怎么用？**
见 [01 · 第五节](01-安装与部署.md#五a-卡amd用户看这里)。部署时显卡选「AMD 显卡（ROCm）」，选对型号。

**Q：报 `operator torchvision::nms does not exist`**
环境里混了 N 卡版的 torchvision。「环境部署」→ 安装目录选你的 WebUI → 显卡选 AMD 和型号 →「把安装目录的环境切换成所选显卡…」，会自动修好。

**Q：A 卡被识别成 N 卡 / GTX 750 之类的**
开了「显卡伪装」软件（比如无极画质助手）。**关掉伪装、重启电脑**，再部署 / 切换环境。

**Q：A 卡第一张图特别慢**
ROCm 第一次要编译，第二张起就正常。

**Q：Forge Classic 能用 A 卡吗？**
不能，用 Neo 或 ComfyUI。

## 出图

**Q：`CUDA out of memory` / `OOM` / 爆显存**
按顺序试：
1. 尺寸调小（SDXL 不要超过 1216×1216）、Batch size 设 1、先关掉 Hires. fix
2. 「高级选项」显存策略选「低显存模式」
3. Neo：UNet 精度选 FP8、VAE 精度选 BF16、文本编码器精度选 FP8 或放 CPU
4. 用 GGUF / fp8 版本的模型
5. NVIDIA 控制面板开「共享显存回退」（会慢，但不报错）

**Q：出图全黑 / 全灰**
「高级选项」计算精度选「全部使用 FP32」；或者 VAE 精度选 FP32 / BF16。

**Q：出图一片噪点 / 彩色雪花**
VAE 没选对。新模型（Anima / Flux / Qwen-Image）必须在 VAE / Text Encoder 框里选配套 VAE，见 [Anima 教程](05-Anima使用教程.md)。

**Q：出的图和提示词完全无关**
文本编码器没选（新模型），或者 LoRA 和大模型的系列不匹配。

**Q：LoRA 没效果**
1. 提示词里有没有 `<lora:名字:0.8>`
2. 有没有写触发词
3. LoRA 的 Base Model 和大模型是不是同一系列（[兼容规则](04-要下哪些模型.md#五兼容性规则很多没效果画崩了都是这里出问题)）

**Q：脸 / 手画崩**
装 ADetailer 插件（「常用插件」一键装），勾上就自动修脸；手用 `hand_yolov8n.pt` 模型。

**Q：出图很慢**
看「一键启动」页日志里 torch 有没有认到显卡（`Device: cuda:0 NVIDIA ...`）。显示 CPU 说明 torch 装成了 CPU 版，「环境部署」→「把安装目录的环境切换成所选显卡…」选 N 卡重装。

**Q：生成的图存在哪？**
Forge Neo：`output\txt2img-images\`、`output\img2img-images\`（Classic 是 `outputs\`）；ComfyUI：`ComfyUI\output\`。最快：「一键启动」页的输出目录按钮，或「输出管理」页。

## 模型

**Q：模型损坏 / `Error while deserializing header` / 文件变成 `.broken`**
下载不完整。删掉重新下载（用启动器下载会自动校验）。

**Q：WebUI 里看不到刚下载的模型**
点下拉框旁边的 🔄 刷新。还没有：在「模型管理」里看它被放到哪了；开了共享模型库要重启一次实例才能挂载上。

**Q：共享模型库改了路径不生效**
老版本的问题，已修复。更新启动器；改完路径后重启实例。

**Q：C 站下载要登录 / 401 / 403**
配置 Civitai API Key，见 [03 · API Key](03-模型下载-C站与liblib.md#需要-api-key-的情况)。

**Q：哩布哩布提示「用户未登录」**
重新复制 usertoken，见 [03 · 第四节](03-模型下载-C站与liblib.md#四哩布哩布liblib下载)。
