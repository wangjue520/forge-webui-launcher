# 04 · 要下哪些模型

> [← 返回教程目录](README.md)

**一句话版**：先下 **1 个大模型** 就能出图了，其他都是锦上添花。
二次元 → 一个 Illustrious / NoobAI 系的 SDXL 大模型，或者 [Anima](05-Anima使用教程.md)；写实 → 一个 SDXL 写实大模型。

---

## 一、模型种类：哪些必须，哪些可选

| 类型 | 是什么 | 必须吗 | 大小 |
|---|---|---|---|
| **Checkpoint（大模型 / 底模）** | 决定整体画风和能力，**出图必需** | ✅ 必须，至少一个 | 2~7GB（新模型 4~20GB） |
| **LoRA** | 小补丁：特定角色、画风、服装、姿势 | 可选 | 10MB~几百 MB |
| **VAE** | 把模型的结果「翻译」成图片。SD1.5 / SDXL 大模型基本都**自带**，不用另下 | 一般不用；**Anima / Flux / Qwen-Image 等新模型必须** | 100~300MB |
| **Text Encoder（文本编码器）** | 理解提示词。SD1.5 / SDXL 自带；**新模型要单独下** | 新模型必须 | 1~10GB |
| **Embedding（嵌入）** | 极小的提示词包，常用作负向词（如 EasyNegative） | 可选，SD1.5 时代用得多 | 几十 KB |
| **Upscaler（放大模型）** | 高清修复 / 放大图片用 | 可选，推荐一个 | 几十 MB |
| **ControlNet** | 按线稿、姿势、深度图控制构图 | 进阶 | 几百 MB~几 GB |

---

## 二、按显卡选大模型

先看自己的显存：任务管理器 → 性能 → GPU →「专用 GPU 内存」。

| 显存 | 推荐的模型系列 | 说明 |
|---|---|---|
| 4GB | SD 1.5 | 能跑 SDXL 但很慢，要开低显存模式 |
| 6~8GB | **SDXL 系（Illustrious / NoobAI / Pony / 写实 XL）**、**Anima** | 主力档位，生态最丰富，LoRA 最多 |
| 12GB | 上面全部 + Flux（fp8 / GGUF）、Z-Image Turbo、Qwen-Image（GGUF） | 新模型理解自然语言更好 |
| 16GB 以上 | Flux / Qwen-Image 高精度版、Wan 视频 | |
| 12GB + 48GB 内存以上 | H3 视频（H3 视频版） | 见部署页说明 |

> 内存也很重要：模型放不下显存时会挪到内存。16GB 内存跑 SDXL 够用，跑 Flux / Qwen-Image / 视频建议 32GB 以上。

### 各系列一句话介绍

| 系列（C 站 Base Model 名） | 擅长 | 提示词写法 | 备注 |
|---|---|---|---|
| **SD 1.5** | 什么都能画，但细节、手、文字都弱 | 英文标签 | 老牌、最省显存，LoRA 极多 |
| **SDXL 1.0** | 写实、通用 | 英文标签或短句 | 写实推荐 Juggernaut XL、RealVisXL 这类热门大模型 |
| **Illustrious** | **二次元首选**，认识大量动漫角色和画师 | Danbooru 英文标签 | 基于 SDXL。C 站热门如 WAI-illustrious 系列 |
| **NoobAI** | 二次元，和 Illustrious 同源，角色和画风知识更多 | Danbooru 标签 | 分 eps 和 v-pred 两种，v-pred 版按模型页说明设置 |
| **Pony** | 二次元 / 卡通 / 兽人 | 标签，开头要加 `score_9, score_8_up, …` | LoRA 只能配 Pony |
| **Anima** | 二次元新模型，2B 参数，标签 + 自然语言都懂 | 标签 + 自然语言 | 要单独下文本编码器和 VAE，见 [Anima 教程](05-Anima使用教程.md) |
| **Flux.1 D / Krea** | 写实、自然语言理解强、能写英文字 | 英文自然语言 | 要单独下文本编码器（clip_l + t5xxl）和 VAE（ae） |
| **Z-Image Turbo** | 写实 / 通用，8 步出图，速度快 | 自然语言（中英文都可） | 要单独下文本编码器（Qwen3 4B）和 VAE |
| **Qwen-Image** | 中文理解强、能写中文字 | 中英文自然语言 | 体积大（20B），一般用 GGUF 量化版 |

> **新手推荐路线**：二次元 → 先下一个 Illustrious 大模型（C 站筛选 Base Model = Illustrious、Type = Checkpoint，按下载量排序挑第一页的）；想试新东西 → Anima。写实 → SDXL 写实大模型。

## 三、推荐的「入门包」

### 二次元（8GB 显存）

| 类型 | 下什么 | 放哪 |
|---|---|---|
| 大模型 | 一个 Illustrious 或 NoobAI 系热门 Checkpoint | 启动器自动放 |
| 放大模型 | `4x-UltraSharp` 或 `4x-AnimeSharp`（C 站搜 Upscaler）| 启动器自动放（`models\ESRGAN`） |
| LoRA | 想画的角色 / 画风，**Base Model 选 Illustrious**（NoobAI 大模型也基本通用） | 启动器自动放 |
| 插件 | ADetailer（自动修脸修手）、Tag Autocomplete（标签补全） | 「常用插件」页一键装 |

### 写实（8GB 显存）

| 类型 | 下什么 |
|---|---|
| 大模型 | 一个 SDXL 写实热门 Checkpoint（Base Model = SDXL 1.0） |
| 放大模型 | `4x-UltraSharp` |
| 插件 | ADetailer |

### Anima

见 [05 · Anima 使用教程](05-Anima使用教程.md)：一个主模型 + `qwen_3_06b_base` 文本编码器 + `qwen_image_vae` VAE，三个文件。

## 四、模型放在哪个文件夹

**用启动器的「模型下载」页 / 拖拽上传不用记这个表**。只有自己从别处下载、手动放的时候对照（都在实例根目录下）：

| 模型类型 | Forge Neo | Forge Classic | ComfyUI |
|---|---|---|---|
| Checkpoint 大模型 | `models\Stable-diffusion\` | `models\Stable-diffusion\` | `models\checkpoints\` |
| 新模型的主模型（Anima / Flux / Qwen 单独的 UNet / DiT 文件） | `models\Stable-diffusion\` | — | `models\diffusion_models\` |
| LoRA | `models\Lora\` | `models\Lora\` | `models\loras\` |
| VAE | `models\VAE\` | `models\VAE\` | `models\vae\` |
| 文本编码器 | `models\text_encoder\` | — | `models\text_encoders\` |
| Embedding | `models\embeddings\` | `embeddings\`（根目录） | `models\embeddings\` |
| ControlNet | `models\ControlNet\` | `models\ControlNet\` | `models\controlnet\` |
| 放大模型 | `models\ESRGAN\` | `models\ESRGAN\` | `models\upscale_models\` |

> 开了 [共享模型库](06-模型管理与共享模型库.md#六共享模型库) 的话，放进模型库对应文件夹，所有实例都能用。

## 五、兼容性规则（很多「没效果」「画崩了」都是这里出问题）

1. **LoRA 的 Base Model 要和大模型对上**
   - SD1.5 LoRA → 只能配 SD1.5 大模型
   - Illustrious LoRA → Illustrious、NoobAI 大模型基本通用
   - Pony LoRA → 配 Pony 大模型（配 Illustrious 效果打折）
   - Flux / Anima / Qwen 的 LoRA → 只能配同系列
2. **VAE 也分系列**：SD1.5 的 VAE 不能给 SDXL 用，反之亦然。SDXL 大模型一般自带 VAE，**VAE 选 Automatic / None 就行**
3. **新模型三件套要配齐**：Anima、Flux、Qwen-Image、Z-Image 只下主模型会报错或出噪点图，文本编码器和 VAE 要配套
4. 看到 **GGUF**（`.gguf`）、**fp8**、**nf4** 是「压缩版」，省显存、画质略降，显存不够时选它们

---

## 六、硬盘不够？

- 「实例管理 → 共享模型库」：多个 WebUI / ComfyUI 共用一份模型，不用每个实例各放一份
- 「模型管理」：按大小排序，删掉不用的（会连同预览图一起删）
