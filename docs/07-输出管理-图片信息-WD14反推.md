## 一、输出管理（看所有出过的图）

侧栏「输出管理」：把**所有实例**出的图（和视频）汇总成一个相册，不用一个个文件夹翻。第一次打开会自动扫描建索引，之后新出的图会自动加进来。

> 阵列图（`grids` 文件夹）不收录。

### 筛选

左侧筛选栏可以组合使用：

| 筛选 | 用法 |
|---|---|
| 搜索框 | 搜**提示词**或文件名里的任意文字，比如 `silver hair` |
| 时间 | 今天 / 最近 7 天 / 30 天 / 一年 |
| 类型 | 图片 / 视频 / 其他 |
| 来源实例 | 只看某个 WebUI / ComfyUI 出的 |
| 收藏夹 | 只看某个收藏夹；「新建」建一个收藏夹 |
| 角色 | 按提示词里识别出的角色名筛选 |
| LoRA / 模型 | 只看用某个 LoRA / 大模型出的图（对比不同模型效果很方便） |
| tag | 输入标签按回车，可以加多个，比如 `red hair` |
| 清空筛选 | 一键还原 |

右上角可以切换「最新在前 / 最早在前」；「重新扫描」用于你手动往输出文件夹里拷了图的情况。

### 看大图

点一张图打开详情：
- 左右切换「上一张 / 下一张」（键盘左右方向键也行）
- 放大 / 缩小 / 适应窗口 / 实际大小
- 右侧显示完整生成参数
- 「打开」用系统看图软件打开；「定位」在资源管理器里找到这个文件
- 「**发送到图片信息**」：跳到图片信息页，可以复制参数、检测缺失模型

### 批量操作

点「多选」→ 勾选多张 →「加入收藏夹」或「删除（进回收站）」。删除是进 Windows 回收站，误删能还原。

## 二、图片信息（读取任何图的生成参数）

侧栏「图片信息」。拖一张图进来，就能看到它是**用什么提示词、什么模型、什么参数**生成的。

### 用法

1. 把图片 / 视频**拖进**上方的框（或点「选择图片 / 视频…」，或直接 **Ctrl+V** 粘贴）
2. 下方分区显示：
   - **正向提示词 / 负向提示词**
   - **角色提示词**（NovelAI V4 以上的多角色）
   - **LoRA**（带哈希的可以精确匹配）
   - **Civitai 资源**（图里嵌的 Civitai 标识，点了直接跳模型页）
   - **生成参数**（模型、采样器、步数、CFG、种子、尺寸…）
3. 底部按钮：「复制正向」「复制负向」「复制全部原始参数」

### 支持哪些图

| 来源 | 支持 |
|---|---|
| A1111 / Forge / reForge | ✅ |
| ComfyUI | ✅（真正追踪工作流图，Flux / SD3.5 / Qwen-Image / WAN / HunyuanVideo 等新模型都认；`.json` 工作流文件也能直接拖） |
| NovelAI V3 ~ V5 | ✅（含多角色） |
| Fooocus / SwarmUI / InvokeAI / Draw Things / Easy Diffusion | ✅ |
| 隐写 PNG（参数藏在像素里的） | ✅ |
| **视频** MP4 / MKV / WebM（Forge Neo、H3、ComfyUI 出的） | ✅ |
| LoRA 训练集（图 + 同名 .txt） | ✅ 读 txt 里的标签 |

**读不出参数**的常见原因：截图、微信 / QQ 传过、网站二次压缩过——这些会把参数整段抹掉，没有办法恢复。从 C 站下载要点「下载原图」。

### 缺失模型检测（复刻别人的图必用）

1. 拖入图片后点「**检测缺失模型**」
2. 列出图里用到的所有模型（大模型、LoRA、VAE、Embedding…）和你本地有没有
3. 缺的模型：
   - **有哈希的**（A1111 / Forge 的图一般都有）：在 Civitai 精确找到，勾选直接下载
   - **没哈希的**（ComfyUI 的图一般没有）：显示「按名字搜索」，列出候选，**需要你自己确认选哪个**（同名模型很多，启动器不会替你乱下）
4. 勾好后点「**下载勾选项**」，自动下载并放进正确文件夹

> 前提：「一键启动」页设好了根目录（启动器要知道去哪找你本地的模型）。

### 把参数一键填进 WebUI

1. 「复制全部原始参数」
2. 粘到 WebUI 正向提示词框
3. 点 Generate 按钮下面那排小按钮里的 **↙**（Read generation parameters），提示词、负向、尺寸、步数、种子等全部自动填好

## 三、WD14 反推（图片自动打标签）

侧栏「WD14 反推」：给图片自动生成 Danbooru 风格的标签。用途：
- **训练 LoRA 前打标**（批量给训练图生成同名 .txt）
- 看到一张图不知道怎么描述，反推出标签当提示词参考

这是启动器内置的独立工具，**不用开 WebUI**，也不依赖 WebUI 插件。

### 第一次使用

1. 「模型」下拉框保持默认（想更准选 `wd-eva02-large`，更慢一点）
2. 点「**加载模型**」
3. 首次会自动：安装独立运行环境（`wd14_venv`，几十 MB）+ 下载模型（约 380MB，国内自动走镜像，断点续传）
4. 显示已加载就可以用了，以后不用再下

**下载失败**：点「打开模型下载页面」，把 `model.onnx` 和 `selected_tags.csv` 两个文件下到同一个文件夹（`model.onnx` 比较大，用下载工具会快很多），然后点「手动导入模型…」选那个文件夹。

### 反推

1. 添加图片：
   - 「选择图片…」/「选择文件夹（批量）…」
   - 或者从资源管理器**拖图片 / 文件夹**进列表
   - 或者 **Ctrl+V** 粘贴截图
2. 参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| 常规标签阈值 | 0.35 | 越低标签越多（也更容易出错），越高越少越准 |
| 角色标签阈值 | 0.85 | 识别角色名的把握程度 |
| 包含评分标签 | 关 | 是否输出 safe / questionable / explicit |
| 批量时保存为同名 .txt | 开 | `001.png` 旁边生成 `001.txt`，LoRA 训练直接能用 |

3. 点「**开始反推**」，结果显示在下方，可以直接复制
