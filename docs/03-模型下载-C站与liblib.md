# 03 · 模型下载：C 站（Civitai）和 哩布哩布（liblib）

> [← 返回教程目录](README.md)

**不用记模型该放哪个文件夹**：在启动器「模型下载」页粘贴链接，它会按模型类型自动放进正确的目录（开了共享模型库就放进模型库），下完自动写好封面图和触发词。

不知道该下哪些模型？先看 [04 · 要下哪些模型](04-要下哪些模型.md)。

---

## 一、C 站（Civitai）是什么

[civitai.com](https://civitai.com) 是全球最大的 AI 绘图模型站，大模型、LoRA、Embedding 基本都能在这里找到，每个模型页都有作者给的示例图和推荐参数。

- **国内访问**：网页经常打不开或很慢，**一般需要开梯子**。启动器下载时会自动走系统代理（Clash 等开「系统代理」或 TUN 模式都行）
- **不想开梯子**：用国内的 [哩布哩布 liblib.art](https://www.liblib.art)，见 [第四节](#四哩布哩布liblib下载)
- **注册账号**：不是必须的，但很多模型要登录 / 用 API Key 才能下，建议注册一个（用 Google / GitHub / 邮箱都行）

---

## 二、在 C 站找模型

### 1. 搜索 + 筛选

1. 打开 https://civitai.com/models
2. 顶部搜索框输入关键词（模型名、角色名、画风，英文为主）
3. 用 **Filters（筛选）** 缩小范围，最常用的两个：
   - **Model types（模型类型）**：`Checkpoint`（大模型）、`LoRA`、`Embedding`、`VAE`、`Upscaler`…
   - **Base model（基础模型）**：`SD 1.5`、`SDXL 1.0`、`Illustrious`、`NoobAI`、`Pony`、`Flux.1 D`…
4. 排序选 **Most Downloaded（下载最多）** 或 **Highest Rated（评分最高）**，新手从热门的挑最稳

### 2. 看懂模型页

```
┌──────────────────────────────────────────────────────────┐
│  模型名                                         [Download]│
│  [v3.0] [v2.5] [v2.0]   ← 版本标签，点哪个下哪个            │
│                                                          │
│  示例图（点开能看到这张图的提示词和参数）                    │
│                                                          │
│  右侧 Details：                                           │
│    Type        Checkpoint / LORA ...   ← 模型类型          │
│    Base Model  Illustrious / SDXL ...  ← 基础模型 ★重要     │
│    Trigger Words  xxx                  ← LoRA 的触发词      │
│  Files：xxx.safetensors  6.46 GB        ← 文件              │
│                                                          │
│  About this version / 描述：作者推荐的采样器、步数、CFG …     │
└──────────────────────────────────────────────────────────┘
```

要看的几样东西：

| 项目 | 为什么重要 |
|---|---|
| **Type** | 决定放哪个文件夹（启动器自动处理） |
| **Base Model** | **LoRA 必须和大模型的 Base Model 匹配**。Illustrious 的 LoRA 配 SD1.5 大模型是没用的，甚至会画崩 |
| **Trigger Words** | LoRA 要在提示词里写触发词才生效 |
| **描述 / About this version** | 作者推荐的参数，照着填 |
| **示例图** | 点开示例图能看到完整提示词；点「复制」可以直接用 |
| **文件大小** | SD1.5 大模型约 2GB，SDXL 约 6.5GB，LoRA 几十~几百 MB |

### 3. 挑哪个文件

一个版本下面可能有好几个文件：

- 只选 **`.safetensors`**（不要 `.ckpt`，`.ckpt` 可能藏恶意代码）
- 有 `fp16` / `pruned` 和 `fp32` / `full` 两种时，选 **fp16 / pruned**（体积小一半，出图一样）
- 带 `Training Data` 的是训练素材，不用下

启动器里会默认选中「**主文件**」，一般不用改。

## 三、用启动器下载 C 站模型（推荐）

### 第 1 步：复制链接

在模型页**选好版本**（点上面的版本标签），然后复制浏览器地址栏的网址，形如：

```
https://civitai.com/models/12345/xxxx?modelVersionId=67890
```

> 地址里带 `?modelVersionId=` 的，下的就是你选中的那个版本；不带的默认下最新版本。纯数字 ID（`12345`）也认。

### 第 2 步：粘贴到启动器

1. 打开启动器侧栏 **「模型下载」**
2. 粘贴到「输入 Civitai / liblib 模型网址」框里
3. 点 **「获取信息」**

下面会出现「模型信息」：来源、模型名、**类型（建议放入哪个文件夹）**、版本、**基础模型**，以及文件列表。

### 第 3 步：确认并下载

1. 文件列表里确认选的是主文件（默认已选）
2. 「保存位置」已经自动填好，**一般不用改**
3. 点 **「下载并放入对应文件夹」**

下载特性：
- **断点续传**：网断了 / 关了启动器，再点一次下载会接着下
- **SHA256 校验**：下完自动校验，文件不对会改名为 `.broken` 保留，不会被 WebUI 当正常模型加载
- 下完自动写入**封面图**和**触发词**（「模型管理」页能看到）
- LoRA 开了「自动整理」的话会自动归类到子文件夹

> ⚠ **C 站的类型标错时**：有些文本编码器、VAE 在 C 站被作者标成了「Checkpoint」，启动器会照着标签放进大模型文件夹。下载前看一眼「模型信息」里的类型和「保存位置」，不对就点「浏览…」改成正确的文件夹（对照 [模型放在哪个文件夹](04-要下哪些模型.md#四模型放在哪个文件夹)）。

### 第 4 步：在 WebUI 里用

- 大模型：网页左上角 Checkpoint 下拉框旁边点 🔄 刷新，就能选到
- LoRA：网页 Lora 标签页点 🔄 刷新

**不用重启 WebUI**。

### 需要 API Key 的情况

下载时报「需要登录」「401」「403」「Unauthorized」，说明这个模型要登录才能下（作者设置了、或者是成人内容）。这时配置一次 API Key：

1. 浏览器登录 civitai.com
2. 启动器「模型下载」页点 **「在浏览器中打开并生成 Key」**（会打开 Civitai 账号设置页）
   - 或者手动：右上角头像 → ⚙ **Account settings** → 往下拉到 **API Keys**
3. 点 **+ Add API key**，名字随便填（比如 `wwy`），点 Save
4. **复制**生成的那一串 Key（只显示一次，丢了重新生成一个就行）
5. 粘贴到启动器的「Civitai API Key」框里（自动保存在本地，以后不用再填）
6. 重新点「获取信息」→ 下载

> Key 只保存在你电脑上的配置里，只用于向 Civitai 下载。**不要把 Key 发给别人**。

## 四、哩布哩布（liblib）下载

[liblib.art](https://www.liblib.art) 是国内站，不用梯子，但**所有模型都必须登录才能下载**。

### 第一次：配置 usertoken（只需一次）

1. 浏览器打开 https://www.liblib.art 并**登录**
2. 按 **F12** 打开开发者工具
3. 顶部选 **「应用 / Application」**（找不到就点 `>>` 展开）
4. 左侧 **Cookies** → `https://www.liblib.art`
5. 在列表里找到 **`usertoken`**，双击它的「值 / Value」，Ctrl+C 复制
6. 粘贴到启动器「模型下载」页的「liblib usertoken」框 → 点 **「验证并保存」**
7. 显示你的昵称就是成功了

> token 过一段时间可能会失效（重新登录过、改过密码），下载提示「用户未登录」时重新复制一次即可。

### 下载

1. liblib 模型页复制地址栏网址（形如 `https://www.liblib.art/modelinfo/xxxx?versionUuid=xxxx`）
2. 启动器粘贴 →「获取信息」
3. 链接里没带 `versionUuid` 时，下面会列出所有版本，选一个
4. **检查一下「保存位置」**（liblib 不提供准确的类型信息，启动器是按文件大小和名字猜的，偶尔会猜错，比如把大 LoRA 当成大模型）
5. 「下载并放入对应文件夹」

**会员专属 / 独家模型**：即使填了 token 也可能被拒（账号权限问题），或者作者只允许在线使用、不提供下载。这时点信息卡里的「在浏览器打开 liblib 模型页面」，在网页上手动下载，再用 [拖拽上传](06-模型管理与共享模型库.md#二拖拽上传模型) 放进启动器。

## 五、看到一张好图，想一模一样复刻（强烈推荐）

1. 在 C 站点开一张喜欢的示例图 → 下载**原图**（右上角下载按钮，不要截图）
2. 拖进启动器「**图片信息**」页
3. 提示词、负向词、采样器、步数、CFG、种子、用到的大模型和 LoRA 全部读出来
4. 点 **「检测缺失模型」** → 你电脑上没有的模型会列出来 → 勾选 →「**下载勾选项**」，一次性补齐
5. 点「复制全部原始参数」→ 粘到 WebUI 的提示词框 → 点 Generate 按钮下面那排小按钮里的 ↙（Read generation parameters），参数全部自动填好

> 截图、微信 / QQ 传过的图、网站压缩过的图，参数已经被抹掉了，读不出来。

## 六、不在 C 站 / liblib 的模型

有些模型只发布在 **HuggingFace**（比如 Flux 的官方文件；Anima 的文本编码器和 VAE 在 C 站也有搬运，见 [Anima 教程](05-Anima使用教程.md#二需要下载的-3-个文件)）。启动器的「模型下载」页只认 C 站和 liblib 链接，HuggingFace 的文件这样下：

1. 国内把网址里的 `huggingface.co` 换成 **`hf-mirror.com`**，例如
   `https://hf-mirror.com/circlestone-labs/Anima/tree/main/split_files`
2. 进到文件所在目录，点文件名右边的 **下载图标（↓）**
3. 下好后拖进启动器「模型管理」页对应分类里（自动移动到正确位置），或者手动放进 [对应文件夹](04-要下哪些模型.md#四模型放在哪个文件夹)

> H3 视频版用户：「模型下载」页最上面有「**H3 视频模型一键下载**」，所有 H3 需要的模型勾选后一键下好，不用自己去 HuggingFace 找。会按你的内存大小自动推荐量化档位（内存不到 40GB 默认 Q2，够大默认 Q4）。

## 七、下载常见问题

| 问题 | 处理 |
|---|---|
| 获取信息失败 / 超时 | C 站被墙了：开梯子（系统代理模式）再试；或者用 liblib |
| 需要登录 / 401 / 403 | 配置 [API Key](#需要-api-key-的情况) |
| 下载速度很慢 | C 站文件服务器在国外，开梯子会快很多 |
| 下到一半断了 | 再点一次「下载并放入对应文件夹」，断点续传 |
| 文件变成 `.broken` | 校验不通过（下载损坏），删掉重新下载 |
| WebUI 里找不到刚下的模型 | 点下拉框旁边的 🔄 刷新；还没有就到「模型管理」看看放到哪了 |
| liblib「用户未登录」 | token 失效，重新复制一次 usertoken |
