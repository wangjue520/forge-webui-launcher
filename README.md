# WWY 启动器（ComfyUI / Forge WebUI）

面向不懂 Python 的用户：界面美观、开箱即用、出错有中文提示。
一个启动器同时管理 **ComfyUI** 和 **Forge WebUI**（Neo / Classic），支持多实例同时运行；只用一个的话界面和以前一样简单。
界面用 HTML/CSS/JS 实现（WebView2 渲染），可切换界面风格（默认"终末地 · 工业终端"，另有"极简"）。

> **English TL;DR**: A beginner-proof launcher for ComfyUI & Forge WebUI. Download the ZIP, extract to a pure-English path, double-click `start一键启动.bat` (or place `启动WWY启动器.bat` next to the folder and use that), deploy with one click, download a checkpoint, press Launch. Full UI is in Chinese.

## 功能特性

- **零环境要求**：不需要预装 Python/Git，双击 bat 全自动引导（自动下载便携 Python 3.13 + 创建 .venv 装依赖）
- **一个启动器管两种后端**：ComfyUI 和 Forge WebUI 都支持，自动识别安装类型
- **多实例**：登记/部署多个实例、同时运行（端口自动错开）、一键切换；只有一个实例时相关界面全部隐藏
- **共享模型库**：所有实例共用一份模型（ComfyUI 走 extra_model_paths，WebUI 走 --ckpt-dir 等），合并按内容去重、可撤销
- **一键部署**：Forge Neo（推荐）/ Classic / ComfyUI，便携 Python + Git + 源码 + torch 预下载全自动
- **一键更新**：启动器本体在「启动器设置」里一键升级（git 增量 / ZIP 覆盖自动选择），配置和环境全部保留
- **启动管理**：一键启动/停止（整棵进程树干净退出）、实时日志、就绪自动开浏览器、端口占用/残留进程预检
- **输出管理器**：所有实例的出图统一索引（阵列图 grids 不收录），按时间、角色、LoRA、模型、tag、来源实例筛选，支持收藏夹、多选删除
- **模型工具**：Civitai / 哩布哩布链接下载（断点续传 + SHA256 校验）、模型管理、哈希查询补全信息、拖拽上传
- **LoRA 自动整理**：按底模/类型自动分进子文件夹，同步修正 ComfyUI 已保存工作流里的路径，可撤销
- **WD14 反推**：图片自动打标签，独立环境不污染主环境
- **图片信息**：读取/编辑 A1111、ComfyUI、NovelAI 等来源的生成参数，可检测并补齐缺失模型
- **常用插件一键安装**：按分支自动适配兼容版本；ComfyUI 实例装进 custom_nodes
- **国内网络优化**：按 IP 归属地自动判断走 GitHub 加速代理 / PyPI 镜像 / HF 镜像，失败自动回退官方源

## 快速上手（五步）

> **太长不看版**：解压到纯英文路径 → 双击 bat → 部署 → 下模型 → 点启动。

### 〇、准备

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10（1803+）/ 11，64 位 |
| 显卡 | NVIDIA 6GB+ 显存体验较好；4GB 可跑（低显存模式）；纯 CPU 也行但很慢 |
| 硬盘 | 至少预留 **25GB**（Forge 本体+依赖约 10GB，一个大模型 2~7GB） |
| 软件 | **什么都不用装**，Python/Git 由启动器自动下载便携版 |

### 一、下载并解压

1. 仓库主页 → 绿色 **Code** → **Download ZIP**（或 `git clone`）
2. 解压到**纯英文路径**，如 `D:\forge-launcher`。避免桌面（中文用户名）、空格、`(1)` 这类括号——路径带中文/括号是绝大多数"莫名报错"的根源
3. **不要在压缩包里直接双击运行**，先完整解压

解压出来的结构：

```
D:\forge-launcher\
├─ forge-webui-launcher\    ← 启动器本体（里面的文件不用动）
└─ 启动WWY启动器.bat         ← 把压缩包里的这个 bat 移到文件夹旁边，以后双击它
```

`启动WWY启动器.bat` 放在文件夹**旁边**就能用（它会自动找到旁边的 `forge-webui-launcher` 文件夹），普通用户永远不需要打开启动器文件夹。直接双击文件夹里的 `start一键启动.bat` 效果完全一样。

### 二、第一次双击 bat

黑色命令行窗口自动完成：下载便携 Python 3.13（约 30MB，带官方哈希校验）→ 创建 `.venv` 虚拟环境 → 装依赖。全程不碰系统里已装的 Python。第一次约 1~3 分钟，网络抖动会自动重试，失败一般再双击一次就好。之后弹出启动器窗口。

- **窗口白屏**：极少数精简系统缺 WebView2 运行时，装一下微软官方的即可：https://developer.microsoft.com/microsoft-edge/webview2/
- 界面太大/太小：**Ctrl + 滚轮**缩放，自动记住

### 三、部署

> 只有第一次需要。已有秋叶整合包等现成安装的话，跳过部署，直接在「一键启动」页选根目录即可。

1. 打开 **「环境部署」**（多实例模式下在「实例管理 → 部署新的实例…」）
2. 分支保持默认 **Neo 版（推荐）**；要 ComfyUI 就选 ComfyUI
3. 「浏览…」选一个**空的或不存在的目录**（同样建议纯英文路径，如 `D:\forge`）
4. 保持勾选「自动下载便携版 Python + Git」
5. 点 **「开始部署」**，全自动：便携环境（1~5 分钟）→ 拉取源码 → 装依赖（10 分钟~1 小时，没有进度条只有日志和心跳，**不是卡死**）→ 自动验证

随时可以取消；网络断了再点一次「开始部署」会**从断点继续**。装到新目录会自动登记为新实例。

### 四、下载一个大模型

1. 去 [Civitai](https://civitai.com) 或 [哩布哩布](https://www.liblib.art)（国内站）挑一个 Checkpoint，复制网页链接
2. 启动器 **「模型下载」** 页粘贴链接 →「获取信息」→ 选文件 →「下载并放入对应文件夹」
3. 保存位置按模型类型自动填好；断点续传；下完自动校验 + 写入封面和触发词

哩布哩布必须登录：浏览器登录 → F12 → 应用(Application) → Cookies → 复制 `usertoken` → 粘到「模型下载」页 →「验证并保存」。Civitai 普通模型不用 Key，受限内容才需要在 Civitai 网站生成 API Key。

### 五、启动出图

1. **「一键启动」**页点 **「一键启动」**（按钮会立刻变成"启动前检查…"）
2. 日志出现监听地址后浏览器自动打开；WebUI 左上角选好大模型，写提示词，点生成
3. 关闭：先在启动器点**「停止」**（干净杀掉整棵进程树），再关窗口；实例还在跑就直接关窗会弹确认框（确认框会列出是哪些实例在跑）

出图默认在 `output\txt2img-images\` 等目录；启动页有一排输出目录按钮，也可以在**「输出管理」**页统一浏览所有实例的出图。

## 页面详解

侧栏页面可以在「启动器设置 → 功能开关」里按需隐藏。

### 一键启动

日常主页。多实例时顶部有所有实例的**状态卡片**（每个实例都能单独启动/停止，不用先切换）；启动参数预览、输出目录按钮组、实时日志（多实例的日志会带 `—— 实例「xxx」的日志 ——` 分隔标题）。

**点启动时可能遇到的弹窗：**

| 弹窗 | 意思 | 怎么选 |
|---|---|---|
| 检测到残留进程 | 上次没退干净，端口被占 | 「结束并启动」 |
| 检测到配置冲突 | 整合包的 webui-user.bat 写死了旧配置 | 「清空并启动」（原文件自动备份 .bak） |
| 路径含中文/空格 | 部分依赖有历史 bug | 建议换纯英文路径，也可以先继续 |
| --listen + 允许不安全扩展访问 | 局域网任何人都能往你电脑装代码，危险 | 至少关掉一个 |

### 实例管理（多实例时显示）

每个实例一张卡片：改名、换根目录、单独端口、单独启动/停止、设为当前、移除（不移除文件）。
「添加已有安装」登记电脑里现成的 ComfyUI / WebUI；「部署新的实例…」进入部署流程，装完自动登记。
下方是**共享模型库**开关和**文件移动记录**（模型合并、LoRA 整理都能在这里撤销）。

「当前实例」（侧栏顶部切换）决定一键启动、常用插件、模型管理这几页操作谁；**高级选项页有自己的实例选择器**，改谁的设置不用切换当前实例。

### 高级选项（按实例分别设置）

页面顶部选择**要设置的实例**（多实例时显示），每个实例的参数各存各的。改动即自动保存。

- **所属分支**：决定参数体系（Neo 新参数 / Neo 旧参数 / Classic / ComfyUI），部署后自动填对
- **性能设置**：GPU 编号、显存策略、计算精度、注意力加速库等——**小白全部保持"自动"**，需要手动调的场景见[下文](#启动参数怎么选显存精度)。ComfyUI 实例显示的是 ComfyUI 版文案和专属加速开关（Sage/Flash/--fast）
- **网络与其他**：局域网访问、API、公网分享、端口、自定义追加参数、网页主题
- **仅供参考**（仅 Forge 实例显示）：GPU Weight、共享显存回退等**不生成参数**，只是记录偏好并指路到 WebUI 内的 Settings

### 启动器设置（全局，不属于任何实例）

- **启动器更新**：自动检查新版本；「立即更新」只升级启动器自身代码，配置、模型、环境全部保留，更新完重启启动器生效
- **多实例开关**：实例数 ≥ 2 时自动打开且不可关
- **界面风格**：整套皮肤（含开屏动画），切换立即生效，开屏动画下次启动生效，详见[界面风格](#界面风格)
- **LoRA 自动整理**：新下载/上传的 LoRA 按底模/类型自动归类；手动整理在「模型管理 → 整理 LoRA」，先预览再执行、可撤销
- **功能开关**：用不上的页面从侧栏藏起来
- **下载加速**：自动检测（推荐）/ 总是镜像 / 总是官方源；挂了梯子建议"自动"或"总是官方源"

### 环境部署

除首次部署外还有维修工具：重新检测环境、「检测该目录」（已有安装/可续跑残留/非空不可用）、「检测现有 venv 版本」、「写入 hashlib 兼容补丁」（治 `hashlib has no attribute 'file_digest'`）。
Forge 目录整个剪切搬家也没问题——启动前会自动修正 venv 里记录的旧路径。
多实例模式下本页从侧栏收进「实例管理」页，功能完全一样。

### 模型下载（C 站 · liblib）

粘贴 Civitai / 哩布哩布链接（版本链接、纯 ID 也认）→「获取信息」→ 选文件 → 下载。断点续传；SHA256 校验不过的文件改名 `.broken` 保留，不会被当正常模型加载。

### 模型管理

按类别浏览（大模型/LoRA/VAE/Embedding/ControlNet…），关键字过滤、基础模型筛选、表头排序；悬停行内直接 定位文件/复制名称/复制 LoRA 调用格式；「哈希查询补全信息」按 SHA-256 精准匹配 Civitai（查不到再查 liblib）写回触发词和封面；详情区可手动编辑触发词（手动填的永远不会被站点查询覆盖）。**支持把模型文件直接拖进页面上传**。

### 输出管理

所有实例的出图统一索引成相册：按时间、类型（图片/视频）、来源实例、收藏夹、角色、LoRA、模型、tag 筛选，支持提示词全文搜索。阵列图（grids 目录）不收录。右侧详情抽屉可以看完整参数、发去「图片信息」页、多选删除（进回收站）、收藏夹管理。缩略图由前端生成缓存，原图走带一次性 token 的本地服务。

### 常用插件

勾选 →「安装选中项」→ 装完重启 WebUI 生效。列表按当前实例的分支自动适配（Neo 上不能用的隐藏，需要专门分支的自动换源）；ComfyUI 实例装进 custom_nodes。

### WD14 反推

图片自动打标签（LoRA 训练打标用），内置独立工具，不依赖 WebUI。首次使用点「加载模型」自动下载（约 380MB，走 HF 镜像、断点续传）并部署隔离环境 `wd14_venv`。图片拖进列表 / Ctrl+V 粘贴截图都行；默认批量时保存同名 .txt。阈值默认 0.35 / 0.85；要更准换 `wd-eva02-large`。

### 图片信息

拖入图片读出全部生成参数。支持 PNG / JPG / WebP / ComfyUI 工作流 json / Ctrl+V 粘贴；来源覆盖 A1111 / Forge / reForge、ComfyUI（真正遍历工作流图）、NovelAI V3–V5（多角色插槽）、Fooocus / SwarmUI / InvokeAI / Draw Things、隐写 PNG、LoRA 训练集同名 txt。**缺失模型检测**：带哈希的精确反查 Civitai 可勾选直接下载；无哈希的按名字搜索、人工确认候选，不会乱下。

## 多实例与共享模型库

- **添加第二个实例后，多实例功能自动打开**：侧栏出现实例切换器和「实例管理」页，启动页出现所有实例的状态卡片
- **同时运行**：各实例端口自动错开（WebUI 7860 起、ComfyUI 8188 起），同一张显卡跑多个实例容易爆显存，启动时会提醒
- **共享模型库**：在「实例管理」页开启并选一个独立文件夹（不要放在任何实例目录里），所有实例启动时自动挂载；「合并各实例已有模型…」会把散在各处的模型收进模型库，按内容去重（重复进回收站），执行前出预览、执行后可撤销

## 启动参数怎么选（显存/精度）

在「高级选项」页配置（每个实例各存各的）。**普通用户全部保持"自动"即可**——Forge / ComfyUI 都会自己管显存。遇到问题再动：

| 症状 | 试试 |
|---|---|
| 显存不够、报 OOM | 显存策略选「低显存 --lowvram」；Forge Neo 再把 VAE 精度选 BF16 |
| 出图全黑/全灰 | 计算精度选「全部使用 FP32」 |
| 40/50 系显卡压榨性能 | Neo 专属的 `--fast-fp16`、`--expandable-segments`；ComfyUI 的 Sage-Attention |
| 显存吃满桌面卡死 | Neo「预留显存」填 1~2（GB） |

Forge 有两套互不兼容的参数体系（Neo 新参数 `--normalvram` 等，Classic/旧 Neo 用 `--always-xxx-vram`），启动器按分支自动生成对的，不用背。

## 国内网络加速与下载安全

启动器自动探测网络环境（「启动器设置 → 下载加速」可重新检测或强制指定）：

| 环节 | 加速方式 |
|---|---|
| GitHub 下载/克隆 | 加速代理多候选逐个试，原站兜底 |
| pip 依赖 | 清华 → 阿里 → 官方源逐个尝试 |
| torch（几个 GB） | 部署时启动器**外置预下载**（断点续传 + sha256 校验 + 交大/清华/官方轮换），装好后 Forge 自动跳过自己的安装 |
| HuggingFace 模型 | 自动切 hf-mirror.com |

**下载安全**：凡经加速代理下载的二进制（Python/Git/源码）一律**强制来源校验**——哈希基准取自官方 release 校验清单并与 GitHub API 交叉核对，解压/执行前强制比对 sha256，Git 安装包额外验微软 Authenticode 签名。校验不过自动换地址重下，全部不符宁可中止也不执行来源不可证的东西。

## 常见问题 FAQ

**Q1：双击 bat 第一次失败，再双击又好了**
便携 Python 下载走的加速代理偶尔抖动，启动器会自己等几秒重试；反复失败就挂好代理再来一次。

**Q2：窗口白屏或提示 WebView2 错误**
系统缺 Edge WebView2 运行时（极少数精简版系统），装微软官方的即可（免费）：https://developer.microsoft.com/microsoft-edge/webview2/

**Q3：bat 一闪而过 / "不是内部或外部命令"**
换**纯英文路径**；不要从压缩包里直接运行。

**Q4：部署时提示"此时不应有 X"**
安装路径含 `()`、`&`、`^`、`%`、`!` 等字符（常见：浏览器重复下载导致文件夹带 `(1)`）。换纯英文路径重新部署，这是 Windows 命令行自身的限制。

**Q5：启动时报端口被占用**
上次没退干净。预检弹窗里选「结束并启动」，或重启电脑。

**Q6：提示 venv 版本不一致 / "Requires-Python >=3.x"**
「环境部署」页点「检测现有 venv 版本」→ 删除 venv，下次启动自动用正确的 Python 重建。

**Q7：加载模型报 "hashlib has no attribute file_digest"**
老 venv 缺 Python 3.11 的新方法。「环境部署」页点「写入 hashlib 兼容补丁」即可。

**Q8：哩布哩布提示"用户未登录"**
见[第四步](#四下载一个大模型)的 usertoken 配置方法。

**Q9：torch 下载到一半断了**
直接再点「开始部署」，断点续传，进度不丢。

**Q10：装好了但网页没自动打开 / 一直"启动中"**
日志里有 `Running on local URL` 但没开浏览器 → 点「在浏览器中打开」。有红字报错 → 把最后 20 行截图发 Issue。

**Q11：杀软报毒 / 文件被删**
便携 Python/Git 来自官方 release（带哈希+签名校验），国产杀软可能误报。把启动器目录和部署目录加入白名单后重试。

**Q12：如何更新 Forge 本体**
「环境部署」页对已有目录再点一次「开始部署」——跳过克隆，只更新依赖并验证可启动。Neo 的日常更新也可以用 WebUI 网页里的内置更新。

**Q13：加速代理下载的东西安全吗？**
每个经代理的二进制都做强制的官方哈希基准校验 + sha256 比对 +（Git）Authenticode 签名验证，不过就中止，绝不执行来源不可证的东西。

**Q14：提示"没有可用的哈希校验基准，已中止（安全策略）"**
没能拿到官方校验清单（GitHub API 和原站都被挡）。换网络/挂代理后重新部署。

**Q15：拉取代码报 CRYPT_E_NO_REVOCATION_CHECK (0x80092012)**
Windows 版 git 用 Schannel 握手前要联网查证书吊销状态，该地址在国内常不可达。启动器部署时会自动关闭便携 Git 的这个检查（只影响启动器自己那份 git）。手动装的 git 遇到可执行一次：`git config --system http.schannelCheckRevoke false`。

**Q16：启动报 "ImportError: Failed to initialize: Bad git executable"**
旧版启动器把带引号的 GIT 路径喂给了 GitPython。升级到新版即可，或把部署目录换到无空格纯英文路径。

**Q17：装依赖报 externally-managed-environment / "managed by uv"**
系统 Python 被 uv 等工具托管（PEP 668 禁止 pip 直装）。最新版启动器完全不碰系统 Python：自动下载便携 Python 装进项目内 `.venv`，任何机器环境一致。

**Q18：启动器自己怎么更新？**
「启动器设置」页顶部「启动器更新」卡片 → 检查更新 → 立即更新 → 重启启动器生效。git 克隆的走增量拉取，ZIP 安装的走整包覆盖；配置、便携环境、WD14 环境、模型缓存全部保留。当前版本号显示在侧栏 logo 下方。

**Q19：生成的图片存在哪？**
Forge 默认 `output\txt2img-images\` / `output\img2img-images\`（Classic 分支是 `outputs\` 复数），ComfyUI 默认 `ComfyUI\output\`。开"按日期分目录"会多一层日期文件夹。最快的办法：「一键启动」页的输出目录按钮，或「输出管理」页统一浏览。

**Q20：自动部署反复失败，有没有手动方案？**
下载完整 Forge Neo 整合包（百度网盘）：https://pan.baidu.com/s/1SV-YxTe-5DhA4PPjDk-neQ?pwd=26u8 （提取码 `26u8`），解压后在「环境部署」页「安装目录」选它，再点「开始部署」——检测到已有安装会跳过源码下载，只补齐环境。

**Q21：启动 ComfyUI 报 No module named 'xxx'**
多半是解释器没指对：ComfyUI 整合包的依赖在它自带的 Python 里。启动器会自动探测常见布局（官方便携包、秋叶整合包的里层/外层、`venv`/`.venv`）；探测不到时在「一键启动」页「Python 解释器」里手动填整合包自带的 `python.exe` 完整路径。

## 进阶：配置文件与目录结构

`launcher_config.json` 首次运行自动生成（实例表、当前实例、界面风格、全局设置都在里面），全部能在界面上改，不需要手改。

```
forge-webui-launcher/
├─ 启动WWY启动器.bat    ← 可移到文件夹旁边当入口（双引用法见上文）
├─ start一键启动.bat     ← 文件夹内的启动入口（自动准备 Python + 依赖）
├─ .venv/               ← 启动器自己的运行环境（首次自动创建，删了自动重建）
├─ python/              ← 自动下载的便携 Python 3.13（没有才建）
├─ launcher_data/       ← 运行期数据：输出索引、缩略图、下载缓存、移动记录（更新时保留）
├─ webview_main.py      ← 入口：创建窗口、关闭前确认
├─ webview_api.py       ← JS ↔ Python 桥接层：所有页面逻辑、事件推送
├─ process_manager.py   ← 每个实例一个启动器（进程树/端口/就绪判定）
├─ model_library.py     ← 拖拽上传、共享模型库合并去重、LoRA 整理、移动记录与撤销
├─ output_index.py      ← 输出管理器：SQLite 索引、角色识别、收藏夹、本地文件服务
├─ config_manager.py    ← 配置读写、实例管理、命令行参数生成、环境检测
├─ portable_env.py      ← 便携 Python/Git 下载、venv 检测、hashlib 补丁
├─ updater.py           ← 启动器自更新（版本号管理、GitHub 检查、增量升级）
├─ version.json         ← 当前版本号（每次更新自动重写）
├─ mirror_manager.py    ← 国内镜像加速
├─ civitai_downloader.py / liblib_client.py / safetensors_meta.py / image_meta_core.py
├─ meta_engine/         ← 图片元数据读写引擎
├─ wd14_*.py            ← WD14 反推（独立 venv）
└─ web/                 ← 前端（index.html / style.css / splash.css / js/ / themes/）
```

**前端联调**：浏览器打开 `web/index.html?mock=1` 可预览界面（注入标注了"演示数据"的假数据，底部有常驻提示条；不带 `?mock=1` 不会启用 mock）。支持 `?page=xxx` 直接定位页面。

**依赖**：只有 `pywebview`（界面）和 `requests`（下载/查询），全部装进项目内 `.venv`，不碰系统 Python（因此 uv 托管 / PEP 668 的 Python 也能用）。
