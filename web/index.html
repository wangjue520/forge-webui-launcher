虚拟环境依赖

          
          
Python 来自 astral-sh/python-build-standalone（uv 底层用的同一套真正独立、可重定位的 CPython 构建，不是阉割过 venv 的官方 embeddable 包）；Git 来自 git-for-windows 官方 PortableGit。两者都是运行时从 GitHub 实时查询最新版本下载，体积加起来大概 100~150MB。勾选后即使系统一个都没装也能部署。

        


        

          
环境诊断对已有安装做检测/修复，不需要重新部署

          
如果你是已有安装（比如秋叶整合包）想检查一下 venv 版本对不对，或者遇到过 "hashlib has no attribute 'file_digest'" 这个报错，用下面两个按钮就够了，不用走完整的克隆部署流程。

          

            
            
          

          

        


        

          
          
        

        

        
部署过程会先（视情况）下载便携版 Python/Git，再执行 git clone 下载源码，然后通过环境变量的方式直接运行仓库自带的 webui.bat——这一步会由 Forge 自己创建 venv 虚拟环境并下载安装 torch 等依赖（体积较大，根据网速可能需要十几分钟到几十分钟）。安装完成后会自动填回「一键启动」页。

Civitai API Key下载受限/需登录内容时才需要，可留空

          

            
            
          

          
做不到「自动登录」——Civitai 没有开放给第三方程序的自动登录接口，真做的话得替你存密码，这个风险不会承担。点右边按钮会跳转到 Civitai 的 Key 管理页（浏览器已登录的话直接跳过登录），生成后复制粘贴回来即可，之后保存在本地配置里不用每次填。

        


        

          
liblib usertokenliblib 所有模型都强制登录才能下载，只看不下的话可以留空

          

            
            
            
          

          
获取方法：浏览器打开 liblib.art 并登录 → 按 F12 打开开发者工具 → 「应用 / Application」→ 左侧 Cookies → www.liblib.art → 找到 usertoken，把它的值复制粘贴到这里 → 点「验证并保存」（验证成功会显示你的昵称）。凭证只存在本地配置里，不会发给 liblib 以外的任何服务器。会员 / 独家模型即使填了 token 也可能被拒（那属于账号权限问题），这时请用信息卡里的「打开模型页面」在浏览器里下载。
